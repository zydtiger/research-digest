# Goal

Surface the research and model releases that are drawing attention and may have
groundbreaking effects across LLM, NLP, diffusion, computer vision, speech, and
quant finance, in one weekly note, without spending agent tokens on filtering or
reading.

## Success criteria

- A weekly run completes unattended and writes a useful note to Obsidian.
- Backtests rank work that later drew wide attention near the top.
- The agent reads roughly 10–20k tokens of input per week.
- Every key claim in a local-model summary traces to a quotation found in its
  source text.

## Non-goals

- LinkedIn and RedNote ingestion.
- A daily digest.
- A database or vector store of everything seen.
- Personalized filtering by similarity to a paper library.

## Constraints

- Scoring and full-text reading use local models only.
- Endpoints, model names, and personal settings live outside this repository.
